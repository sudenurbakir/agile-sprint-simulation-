# User Stories

## Amaç

Bu doküman, Sprint 01 kapsamında geliştirilecek işlevler için kullanıcı ihtiyaçlarını User Story formatında tanımlamak amacıyla hazırlanmıştır.

# User Stories

| ----- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| US-01 | PB-01              | **Kullanıcı olarak**, hesabıma giriş yapmak istiyorum, **böylece** kişisel görevlerime güvenli bir şekilde erişebilirim.                    | Yüksek  |
| US-02 | PB-02              | **Kullanıcı olarak**, yeni bir görev oluşturmak istiyorum, **böylece** yapmam gereken işleri planlayabilirim.                               | Yüksek  |
