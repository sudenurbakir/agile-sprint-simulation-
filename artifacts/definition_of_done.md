# Definition of Done

## Amaç

Bu doküman, Sprint kapsamında geliştirilen iş kalemlerinin **Done (Tamamlandı)** durumuna alınabilmesi için karşılanması gereken ortak kalite kriterlerini tanımlamak amacıyla hazırlanmıştır.

---

# Definition of Done

Bir Product Backlog öğesi veya User Story, aşağıdaki kriterlerin tamamını karşıladığında **Done** olarak kabul edilir.

| No     | Tamamlanma Kriteri                                                   |
| ------ | -------------------------------------------------------------------- |
| DoD-01 | Geliştirme çalışması tamamlanmış olmalıdır.                          |
| DoD-02 | İlgili fonksiyonel gereksinimler karşılanmış olmalıdır.              |
| DoD-03 | User Story'de tanımlanan iş ihtiyacı eksiksiz karşılanmış olmalıdır. |
| DoD-04 | Acceptance Criteria maddelerinin tamamı sağlanmış olmalıdır.         |
| DoD-05 | Kritik veya yüksek öncelikli hata bulunmamalıdır.                    |
| DoD-06 | Gerekli testler başarıyla tamamlanmış olmalıdır.                     |
| DoD-07 | Product Owner tarafından kabul edilmiş olmalıdır.                    |
| DoD-08 | İlgili dokümanlar güncellenmiş olmalıdır.                            |

---

# Kullanım Amacı

Definition of Done, Scrum takımındaki tüm ekip üyelerinin "tamamlandı" kavramını aynı şekilde yorumlamasını sağlar.

Bu sayede;

* Ortak bir kalite standardı oluşturulur.
* Eksik teslimatlar önlenir.
* Sprint sonunda teslim edilen işlerin güvenilirliği artırılır.
* Product Backlog öğeleri tutarlı kriterlere göre tamamlanır.

---

# Kapsam

Bu kriterler aşağıdaki çalışmalar için uygulanır.

* Product Backlog öğeleri
* Sprint Backlog öğeleri
* User Story'ler
* Sprint kapsamında geliştirilen tüm iş kalemleri

---

# Sorumluluklar

| Rol              | Sorumluluk                                                          |
| ---------------- | ------------------------------------------------------------------- |
| Product Owner    | İş çıktısının kabulünü onaylar.                                     |
| Geliştirme Ekibi | İş kalemini Definition of Done kriterlerine uygun şekilde tamamlar. |
| Scrum Master     | Ekibin Definition of Done standartlarını uygulamasını destekler.    |

---

# Notlar

* Definition of Done, Scrum Takımı tarafından ortaklaşa belirlenen kalite standartlarını ifade eder.
* Gereksinimler veya çalışma süreçleri değiştikçe gözden geçirilebilir ve güncellenebilir.
* Sprint sonunda tamamlanan her iş kalemi, bu dokümanda tanımlanan kriterlere göre değerlendirilmelidir.
