# Product Backlog

## Amaç

Bu doküman, ürün kapsamında geliştirilmesi planlanan işlerin öncelik sırasına göre listelenmesi amacıyla hazırlanmıştır.

---

# Product Backlog

| ID    | Backlog Item                        | Açıklama                                                | Öncelik | Durum   |
| ----- | ----------------------------------- | ------------------------------------------------------- | ------- | ------- |
| PB-01 | Kullanıcı girişi                    | Kullanıcının uygulamaya giriş yapabilmesi.              | Yüksek  | Backlog |
| PB-02 | Görev oluşturma                     | Kullanıcının yeni görev oluşturabilmesi.                | Yüksek  | Backlog |
| PB-03 | Görev listesini görüntüleme         | Oluşturulan görevlerin listelenmesi.                    | Yüksek  | Backlog |
| PB-04 | Görev güncelleme                    | Mevcut görev bilgilerinin düzenlenebilmesi.             | Orta    | Backlog |
| PB-05 | Görevi tamamlandı olarak işaretleme | Kullanıcının tamamlanan görevleri işaretleyebilmesi.    | Orta    | Backlog |
| PB-06 | Görev silme                         | Kullanıcının görevlerini silebilmesi.                   | Orta    | Backlog |
| PB-07 | Görev arama                         | Kullanıcının görevleri anahtar kelime ile arayabilmesi. | Düşük   | Backlog |
| PB-08 | Görev filtreleme                    | Görevlerin durumuna göre filtrelenebilmesi.             | Düşük   | Backlog |

---

# Öncelik Seviyeleri

| Öncelik | Açıklama                                                                                |
| ------- | --------------------------------------------------------------------------------------- |
| Yüksek  | Ürünün temel işlevlerini sağlayan ve ilk sprintlerde geliştirilmesi planlanan işlerdir. |
| Orta    | Temel işlevleri tamamlayan ve kullanıcı deneyimini geliştiren işlerdir.                 |
| Düşük   | İlk sürüm için kritik olmayan, sonraki sprintlerde değerlendirilebilecek işlerdir.      |

---

# Backlog Durumları

| Durum       | Açıklama                                      |
| ----------- | --------------------------------------------- |
| Backlog     | Henüz geliştirme planına alınmamış iş kalemi. |
| Sprint      | Sprint kapsamına alınmış iş kalemi.           |
| In Progress | Geliştirme süreci devam eden iş kalemi.       |
| Done        | Tamamlanmış ve kabul edilmiş iş kalemi.       |

---

# Notlar

* Product Backlog yaşayan bir dokümandır ve ürün geliştirme süreci boyunca güncellenebilir.
* İş kalemleri önceliklerine göre sıralanmıştır.
